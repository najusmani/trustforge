# 22 LOVs for High Volumes
- Block field LOV **Exact Fetch**: exact DB value required, no wildcard (98712 fetches only that account).
- LOV definition **Is Mandatory** per reduction field: blocks blank/`%` total wildcard; **Min Search Char Length** default and minimum 3. Not available for Global LOVs. Example: customer LOV.
- Summary screen: **Criteria Based Search** checkbox; per-field minimum search chars (cannot exceed data-source level value); summary field LOV details (default from LOV, return fields, bind variables).
