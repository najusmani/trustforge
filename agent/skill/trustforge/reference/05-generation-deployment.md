# 05 Screen Development II (generation, deployment, release)
- Generate dialog: New = all files checked; Load = hook packages unchecked by default.
- **Front-end**: `<FID>_RAD.xml`; `<FID>.xml` screen/UIXML (language-specific, XSL to HTML); `<FID>_SYS.js` (vars: msgxml, dataSrcLocationArray, relationArray, retflds/bndFlds, CallFormArray/CallFormRelat/CallRelatType, actionsAmmendArray); `<FID>_<RELEASE_TYPE>.js` release JS — NOT generated, developer writes it: `fnPreLoad_KERNEL()`, `fnPostLoad_KERNEL()`, `fnPreNew_KERNEL()`, `fnPostNew_KERNEL()` etc; CLUSTER overrides KERNEL, CUSTOM overrides both.
- **System packages**: Main package spec/body (never edit; flavours: maintenance, transaction, others, report parameter, notification, purge). Maintenance stages each with Pre/Post hooks: TS to PL/SQL composite type, mandatory checks, default & validate, write DB, query, composite back to TS. Upload package spec/body (adapter upload; converts upload-table data to composite type and calls main). Notification trigger.
- **Hook packages**: Kernel / Cluster / Custom spec+body; each team edits only its own. Put user validations in `Fn_Post_Default_and_Validate` (called after `Fn_Default_and_Validate`). Extra helpers go in a new `<MODULE>PKS_<FID>_UTILS` package, not in generated structure.
- **INC metadata**: Menu (SMTB_MENU, SMTB_FUNCTION_DESCRIPTION, SMTB_ROLE_DETAIL, SMTB_FCC_FCJ_MAPPING — all four needed to launch), CSTB_FID_DATA_SOURCES, CSTB_LOV_INFO, CSTB_FID_DATA_BLOCKS, CSTB_FID_SCREENS, amendable (GWTM_AMEND_MASTER, GWTM_AMEND_NODES, GWTM_AMEND_FIELDS, GWTB_AMEND_NODES, GWTB_AMEND_FIELDS), CSTB_CALL_FORM_NODES (call forms only), CSTB_SUMMARY_INFO, labels (CSTB_FIELD_LABELS, CSTB_OTHER_LABELS; NOT CSTB_LABELS), STTB_AUDIT_PK_COLS, CSTB_FID_CALLFORMS, gateway (GWTM_FCJ_FUNCTIONS, GWTM_OPERATIONS_MASTER), notification (GWTM_NOTIFICATION_TRIGGERS, GWTM_NOTIFICATIONS_MASTER), report params (AETB_FUNC_MASTER, AETB_FUNC_DETAIL), purge (STTM_PURGE_MASTER, STTM_PURGE_TBL_DETAILS, STTM_PURGE_FILTERS).
- **Others**: XSDs (gateway), screen HTML (for doc screenshots), upload table trigger (into CSTB_EXT_CONTRACT_STAT, STTB_UPLOAD_MASTER), upload table DDL, archive table DDL + synonyms (purge).
- **Deploy**: front-end copied to env JS/UIXML paths (File Copy on Windows, File Manager on Windows/UNIX); DB files compiled into env FLEXCUBE schema. Status "Deployed".
- **Release**: Oracle-internal SVN integration; SVN Repository URL in Preferences (path up to module); releases RADXML + main package spc/sql; SFR number unless simple check-in.
