# 24 Customer Landing Page
- Browser node "Customer Landing Page". Header: Action New/Load, Function Id (e.g. STDCULND), Save Xml Path, Function Category = Master / Detail / Summary / Tabs / Subsystems.
- Master: Preferences (same as normal), screen `CVS_Master`, add body tabs (e.g. Tab_1) and map each tab to a function name (e.g. STDDE) with a Tab Type (e.g. Details). Detail = built like an Others screen (module e.g. ST). Summary = like normal summary. Tabs = group of screens, each a detail under a tab. Subsystems = subsystem buttons that launch screens.
