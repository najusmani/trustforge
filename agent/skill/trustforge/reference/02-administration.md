# 02 Administration
- First login: `RADTOOL/RADTOOL` (only for bootstrap; don't develop with it). Use it to create releases and ONE Release Administrator user.
- Admin tree: Release, Environment, User — each has Detailed + Summary screens. Standard toolbar: New, Save, Close, Enter Query, Execute Query, Unlock.
- **Release**: Release Code (mandatory, FLEXCUBE convention e.g. `FC_UBS_V.UM_11.4.US.1.0.0.0`), Release Type (mandatory: KERNEL = kernel team only, CLUSTER = regional teams, CUSTOM = client customization/onsite), Release No, Base Release (used for test-case data migration; e.g. custom over 11.3EU cluster → base 11.3EU), Release SPC (in-house), Stream Name (= DDL stream name), Cluster Name, Custom Name, Release Stage (Dev/SQA/ITR), Application Name (FLEXCUBE, FCIS, FGL), "Migrate Test Case Data from Base Release".
- **Environment** (≥1 per release; many per release allowed; each = one FLEXCUBE env): Env Code (`<release>_ENV`), Release Code, Language (LOV from `RDTM_LANGUAGE`; drives screen XML generation language), JNDI name (mandatory, case-sensitive, must match app-server datasource; connection to FLEXCUBE schema is via JNDI). Dynamic datasource registration if PROVIDER_URL set (e.g. `INITIAL_CONTEXT_FACTORY=weblogic.jndi.WLInitialContextFactory`, `PROVIDER_URL=t3://localhost:7101`); not on Tomcat (read-only JNDI). DB details are informational unless dynamic registration.
  - Application details: Application URL (Launch FCUBS), IP, OS (Windows/UNIX), Transfer Type for Deploy (Windows: File Copy or File Manager; UNIX: File Manager), JS Directory Path, UIXML Directory Path (trailing slash required; Windows paths double-escaped `\\\\host\\js\\`), File Manager URL `http://<ip>:<port>/FileManager/FileManageServlet` + server user/pwd.
- **User**: User ID, name, password, Default Release, Default Environment, Save Format (Zip default / Server Path / Client Path [IE ActiveX only]), Work Directory (`CURRENT_DIRECTORY` = path at design screen), Excel Format (XLS/XLSX), XML Formatting, LDAP Authentication (odt.properties: `LDAPSSLEn`, `LDAP_DOMAIN`, `LDAP_SERVER_URL`).
  - User Releases grid: roles per release — Release Administrator (create envs/users, grant access), Developer (function development), TCM User (TCM screens only), VERCON (bulk generation only). Default release MUST be in the grid or login fails.
- File Manager servlet: deploy on FLEXCUBE app server; `FileManager\WEB-INF\classes\com\ofss\manager\fileupload.properties` lists allowed ODT server IPs (`;`-separated).
