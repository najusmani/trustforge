# 06 Screen Customizer
- Load-only; three nodes (DataBlocks, Screens, FieldSets). No block property changes, no new blocks/fields, no delete/rename of blocks/fields.
- Field props editable: Display Type, Field Size, Preview Value, Popup Edit Required, Visible, Upper Case Only, Read Only.
- Screens/tabs/sections: full add/modify/delete/rename (delete/rename only if created in working release). Field sets: change placement, horizontal, read-only, reorder fields; data block fixed.
- Generates only RADXML, screen (language) XML, SYS JS; deploy UIXML + SYS JS. Examples: hide a field (uncheck Visible); add a tab and move a field set to it.
