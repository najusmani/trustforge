# 21 Service XML and Silent ODT Utility
- **Service XML (SXML)**: one per gateway service, lists function ids + operations. Name `<ServiceName>.sxml` (e.g. `FCUBSCoreService.sxml`); release-segregated like radxml. Service node: Action New/Load, Service Name (LOV GWTM_SERVICES_MASTER; add new services there first), Service Description, Module (LOV SMTB_MODULES, but use source folder module name e.g. `Core` for CS; drives artifact layout), Save Xml Path. Function Id grid: LOV from SMTB_MENU; pick FC_FUNCTION_ID that has a radxml (STDCIF not STGCIF); Extensible flag auto; Type XSD Name (auto for extensible, manual for non-extensible); Operations popup: Load Radxml + Default Operations. Non-extensible function ids: only delete allowed.
- Artifacts: `<Svc>Src\*Impl.java`, `<Svc>WSDL\*.wsdl`, `<Svc>Config\*.xml`, `<Svc>XSD\*.xsd`, `<Svc>Common\*.xsd` (call forms), META-INF application.xml + MANIFEST.MF, commons-codec-1.2.jar, wscommon.jar, sample Ant (WLANTBuild.xml WebLogic, WASAntBuild.xml WebSphere) to build the EAR.
- **SilentODTUtility** (headless ODT): prereqs JDK 1.7, Ant 1.7.1, jaxb-xjc.jar + ojdbc6.jar in lib; clear read-only on sources. Run `silentOdt.bat/.sh`. Config in `/resource`:
  - `SilentOdt.properties`: OdtJdbcUrl (encrypted, e.g. `jdbc:oracle:thin:@host:1521:SID`), OdtDbUser, OdtDbPassword (encrypted), SymmetricKey (exactly 16 chars; same for URL and password; encrypt with `ODTPassEncryption.bat/.sh`), Logreqd Y/N, Logpath, Level (SEVERE..FINEST, default INFO), JAVA_HOME (mandatory), WEBLOGIC_HOME, WAS_HOME (optional, for Ant templates).
  - `ODTOperations.properties`: ordered operations; LOGIN (Userid, encrypted password) and SETRELEASE (relCode, envCode, langCode) mandatory first.
    - BULKGENERATION: radxmlListFile or srcPath (list wins), fileType EXTENSIBLE/NON_EXTENSIBLE/BOTH, destPath, gen = comma list of UIXML, SYS_JS, MAIN_SPC, MAIN_SQL, KERNEL_SPC, KERNEL_SQL, CLUSTER_SPC, CLUSTER_SQL, CUSTOM_SPC, CUSTOM_SQL, UPLOAD_SPC, UPLOAD_SQL, UPLOAD_TRIGGER, UPLOAD_TABLE_DDL, XSD_FILES, MENU_DETAILS, LABEL_DETAILS, AMEND_DETAILS, SUMMARY_DETAILS, SCREEN_DETAILS, LOV_DETAILS, BLOCK_PK_COLS, CALL_FORM_DETAILS, BLOCK_DETAILS, DATASCR_DETAILS, FUNCTION_CALL_FORMS, GATEWAY_DETAILS, NOTIFICATION_DETAILS, FUNCTION_PARAMETERS, NOTIFICATION_TRIGGER, PURGE_DETAILS, ARCHIVE_TBL_DEF.
    - REFRESH: refreshType CHILD_REFRESH / SCRCHILD_REFRESH / SOURCE_REFRESH, srcFileList, baseFileList, srcRelType, baseRelType (KERNEL/CLUSTER/CUSTOM), destpath.
    - SXML_BULKGENERATION: sxmlListFile, radxmlListFile, xsdListFile (or srcPath), gen = IMPL_FILE, CONFIG_FILES, WSDL_FILE, XSD_FILES, GW_WS_PROP_FILES, ANT_BUILD; nonExtServicesReqd Y/N; destpath; validateXsds Y/N (default Y).
    - SXML_UPDATER (operation name SXML_UPDATE): sync operation codes / removed function ids from radxmls into SXMLs (new function ids must be added manually in UI); sxmlListFile, radxmlListFile or srcPath, destpath, confirmStage=SINGLE_STAGE_UPDATE.
    - SXML_REFRESH: srcFileList, baseFileList, srcRelType, baseRelType (base at least one level below), destpath.
  - `GW_CONFIG.properties` (only for GW_WS_PROP_FILES): EJB_APP_NAME, EJB_APP_SERVER, EJB_JNDI_NAME, EJB_SERVER_URL, EJB_SERVER_USERNAME, EJB_SERVER_PASSWORD, GW_WS_LOGGER_PROP_FILE_PATH, GW_WS_LOGGER_FILE_PATH, GW_WS_PROP_FILE_PATH, XSD_PATH.
  - Web service artifact run = LOGIN, SETRELEASE, SXML_BULKGENERATION. Logs: ServiceGenerationStatus.csv (all must be Success), XSDValidationErrors.csv (must not exist), utility log. Gateway props in `GW_WS/`: gw_ws_logger.properties, GW_WS_Prop.properties.
