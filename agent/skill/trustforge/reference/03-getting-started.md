# 03 Getting Started
- Browsers: IE8+ (≥8.0.6001.18702), Firefox, Chrome; 1280x1024. Client-path mode needs IE + ActiveX + MSXML 6.0.
- Browser tree menu (role-based): Administration, Function Generation, Screen Customizer (layout-only changes; no add/delete), Tracking Changes, Notification Triggers, Notification, Bulk Generation, Excel Template Generation, Refresh (upgrade radxml version / propagate parent changes to child radxml), Web Services, Block Detail Upload, Test Case Definition, Run Chart Definition, Test Case Data Upload, Create Request, Test Case Execution, Run Chart Execution, Test Case Data Bulk Upload, Execution Report.
- Toolbar also: LOV, label maintenance, Generate Files, Deploy Files, Release Files.
- User Preferences: switch release/env/language/save mode/work dir/excel format/XML indentation for current session only.
- Change Password, Sign Out, About, Windows menu, Launch FCUBS.
