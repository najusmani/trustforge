# Static data, DDL and INC scripts

> **Lessons first:** before delivering, and first whenever the user reports an ODT save, compile, deploy or test error, read `../../reference/29-lessons-learned.md`; when a new root cause is confirmed, record it as that file describes (automatically).

Reference: `../../reference/05-generation-deployment.md` (INC list), `04-screen-development-core.md` (labels, naming), `16-launch-forms-and-others-screens.md`, `23-upload-framework.md`, `21-service-xml-silent-odt.md`, `25-gateway-lov-enhancer.md`.

## Generated by ODT - do NOT hand-write, list them for compilation
Menu (SMTB_MENU, SMTB_FUNCTION_DESCRIPTION, SMTB_ROLE_DETAIL, SMTB_FCC_FCJ_MAPPING), CSTB_FID_DATA_SOURCES, CSTB_LOV_INFO, CSTB_FID_DATA_BLOCKS, CSTB_FID_SCREENS, amend tables (GWTM_AMEND_MASTER/NODES/FIELDS, GWTB_AMEND_NODES/FIELDS), CSTB_CALL_FORM_NODES (call forms only), CSTB_SUMMARY_INFO, CSTB_FIELD_LABELS, CSTB_OTHER_LABELS, STTB_AUDIT_PK_COLS, CSTB_FID_CALLFORMS, gateway (GWTM_FCJ_FUNCTIONS, GWTM_OPERATIONS_MASTER), notification, report (AETB_FUNC_MASTER/DETAIL), purge (STTM_PURGE_*), CSTB_CMB_LOV_INFO (LOV enhancer), upload trigger + adapter package + upload table DDL.

## Written by hand (this skill)

### 1. Custom tables / columns (DDL)
- Naming: 5th char `_`, no double underscores; synonym = `S` before first `_` (e.g. `XXTM_CUST_EXT` -> `XXTMS_CUST_EXT`). Use the bank's custom prefix if they have one; ask if unknown.
- Prefer a new custom extension table keyed by the master PK (1:1) over altering kernel tables, unless the user requests otherwise. Include the standard audit columns only on masters of Maint Audit screens (MAKER_ID, MAKER_DT_STAMP, CHECKER_ID, CHECKER_DT_STAMP, MOD_NO, RECORD_STAT, AUTH_STAT, ONCE_AUTH).
- Provide: CREATE TABLE / ALTER TABLE ADD, PK constraint, synonym, grants if the user's schema uses them, and a matching rollback script. Make scripts re-runnable where practical.
- Optionally the STTB_PK_COLS row if the user's environment uses it to default PKs (ask for an existing row to copy the column list).

### 2. Labels (CSTB_LABELS)
- ODT does not generate CSTB_LABELS; maintain via ODT Label Code screen (Insert/Update + Deploy) OR a script. Codes start `LBL_`, letters/digits/underscore only; field labels `LBL_<XSDTAG>`; menu labels `LBL_<FID>_MAIN_MENU`, `_SUB_MENU_1`, `_SUB_MENU_2`, `_DESC`.
- For a script, copy column list and style from an existing CSTB_LABELS insert the user provides; otherwise give the label list (code, description, language, type) as a table plus the ODT Label Code screen steps. Never guess column names.

### 3. Launch form CSTB_CALL_FORM_NODES (manual)
- Required for launch forms (not generated). SCREEN_ARGS is `~`-separated and must match the launch form main screen args: `ACTION_CODE` (EXECUTEQUERY) + PK args. Copy the column list from an existing row the user provides.

### 4. Upload framework
- Upload table naming: 4th letter -> U (STTM_CUSTOMER -> STTU_CUSTOMER); consulting/client tables `<table>_U_EXTGBL`.
- Standard columns: SOURCE_CODE, SOURCE_REF (txn) / MAINTENANCE_SEQ_NO (maint), SOURCE_SEQ_NO, BRANCH_CODE (PK); optional FUNCTION_ID, ACTION_CODE, UPLOAD_ID, UPLOAD_STATUS, MODULE, SOURCE_OPERATION. Detail tables add their own unique key.
- ODT generates upload DDL, trigger and `<mod>pks_<fid>_ext_upload`; hand-write only when the user wants to reuse/adjust existing tables. Process tables: CSTB_EXT_CONTRACT_STAT (txn), STTB_UPLOAD_MASTER (maint). Invocation: CVDUPLOD.

### 5. Services
- New SOAP service: row in GWTM_SERVICES_MASTER before creating the .sxml (copy columns from an existing row). REST: enable in Actions; compile generated INCs.

### 6. Error messages
- Custom validation error codes need message maintenance entries. Ask for the bank's code range and an existing message insert to copy; otherwise list code + text for the user to maintain.

## Output
`output/db/ddl/` (create + rollback), `output/db/static/` (labels, call form nodes, services, messages) and a "Compile list" section in CHANGES.md: DDL -> generated INCs -> MAIN spc/sql -> CUSTOM spc/sql -> manual static scripts.
